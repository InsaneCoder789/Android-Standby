# Standby design review · 6 November 2026

This package is design-only. It contains an app-flow proposal, a source inspection of the existing frames, frame design briefs, and AI-generated raster prototypes being prepared for review.

The primary concept set covers all 23 frames. Alternative looks within each frame are documented separately; a primary concept does not imply that every variant has been rendered or implemented.

Prototypes use mock data. Images demonstrate proposed visual direction and composition, not working Android controls, sensor behavior, phone integration, or evidence that runtime bugs have been fixed. Implementation and physical-device verification remain separate work.
