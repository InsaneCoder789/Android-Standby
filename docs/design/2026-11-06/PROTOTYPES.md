# Standby redesign prototypes

Design review only. 23 primary frame concepts, 3 default variants, 4 app screens and 3 new frames. Mock content; no app implementation changed.

Generated raster details such as dates, time zones, calendar arithmetic, variant counts and small labels are illustrative and require correction in a precise implementation. Fixed-digit stability, motion and accessibility cannot be verified from these images.
